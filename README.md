# ONG Esperança

## 1. Apresentação

O projeto **ONG Esperança** foi desenvolvido como parte das atividades práticas da disciplina de **Desenvolvimento Front-End**, com o objetivo de aplicar, de forma prática, conhecimentos relacionados ao desenvolvimento de aplicações web.

A proposta consiste na criação de um website institucional para uma organização não governamental fictícia, apresentando suas informações, projetos, formas de participação e canais de contato. Durante o desenvolvimento, foram aplicados conceitos de estruturação semântica, estilização, responsividade, acessibilidade, interatividade e publicação em ambiente de produção.

## 2. Objetivo do projeto

O principal objetivo do projeto é desenvolver uma aplicação web organizada, responsiva e acessível, capaz de apresentar as informações da ONG Esperança de maneira clara e proporcionar uma experiência de navegação adequada aos diferentes usuários e dispositivos.

Além da construção da interface, o projeto teve como finalidade colocar em prática conceitos estudados durante a disciplina, permitindo compreender melhor as etapas envolvidas no desenvolvimento de uma aplicação Front-End, desde sua estrutura inicial até sua publicação.

## 3. Tecnologias utilizadas

O projeto foi desenvolvido utilizando as seguintes tecnologias e ferramentas:

* **HTML5:** utilizado para a estruturação e organização semântica das páginas;
* **CSS3:** utilizado para a estilização, organização visual, responsividade e criação dos diferentes componentes da interface;
* **JavaScript:** utilizado para implementar funcionalidades interativas, validações e comportamentos dinâmicos da aplicação;
* **Git:** utilizado para o controle de versão do projeto;
* **GitHub:** utilizado para armazenamento e gerenciamento do código-fonte;
* **Vercel:** utilizada para a publicação da aplicação em ambiente de produção.

## 4. Estrutura do projeto

O projeto é composto pelos principais arquivos:

* `index.html` — página inicial e apresentação institucional da ONG;
* `projetos.html` — apresentação dos projetos e formas de participação;
* `cadastro.html` — formulário de cadastro;
* `style.css` — estilos visuais e responsividade da aplicação;
* `script.js` — funcionalidades e interações gerais da interface;
* `form.js` — validações e funcionalidades relacionadas ao formulário;
* `templates.js` — estruturas utilizadas para determinados elementos dinâmicos;
* `router.js` — arquivo presente na estrutura do projeto para organização da navegação;
* arquivos de imagem — recursos visuais utilizados na composição da interface.

## 5. Funcionalidades implementadas

Durante o desenvolvimento, foram implementadas diferentes funcionalidades, entre elas:

* navegação entre as páginas do projeto;
* menu de navegação para dispositivos móveis;
* layout responsivo para diferentes tamanhos de tela;
* formulário de cadastro;
* validação dos dados inseridos no formulário;
* mensagens de feedback ao usuário;
* organização semântica das páginas;
* utilização de atributos ARIA para melhorar a acessibilidade;
* adaptação da interface para dispositivos móveis;
* apresentação institucional da ONG;
* apresentação dos projetos e formas de participação;
* publicação da aplicação em ambiente de produção.

## 6. Acessibilidade

A acessibilidade foi considerada durante o desenvolvimento da aplicação por meio da utilização de elementos HTML semânticos e atributos ARIA.

Foram utilizados elementos como `header`, `nav`, `main`, `section` e `footer`, contribuindo para uma melhor organização estrutural do conteúdo. Também foram utilizados atributos como `aria-label` e `aria-expanded` em elementos de navegação e interação.

Além disso, foram considerados critérios relacionados ao contraste de cores, tendo como referência as diretrizes da **WCAG 2.1**, buscando proporcionar melhor legibilidade e acesso ao conteúdo.

## 7. Responsividade

O projeto foi desenvolvido considerando diferentes tamanhos de tela. Foram utilizados recursos de CSS para adaptar a estrutura e a disposição dos elementos em dispositivos menores.

Na versão para telas reduzidas, a navegação principal é substituída por um menu mobile, permitindo que os usuários acessem as páginas de forma mais adequada. Também foram realizados ajustes nos elementos visuais para melhorar a apresentação do conteúdo em dispositivos móveis.

## 8. Controle de versão

O desenvolvimento do projeto foi acompanhado utilizando **Git e GitHub**, permitindo registrar as alterações realizadas ao longo das etapas.

Foram utilizadas branches para organizar o desenvolvimento, incluindo as branches `main`, `develop` e `feature/acessibilidade`. Também foram realizados commits para registrar alterações relacionadas à estrutura do projeto, acessibilidade e finalização da aplicação.

Essa organização possibilitou acompanhar a evolução do projeto e manter uma versão final disponível no repositório remoto.

## 9. Publicação em ambiente de produção

Após a finalização do desenvolvimento, o projeto foi integrado ao repositório do GitHub e publicado utilizando a plataforma **Vercel**.

A integração entre o repositório e a plataforma de hospedagem permite que as alterações enviadas ao GitHub sejam utilizadas no processo de atualização da aplicação publicada.

A versão disponibilizada em ambiente de produção pode ser acessada pelo seguinte endereço:

https://ong-esperanca-six.vercel.app/

## 10. Considerações finais

O desenvolvimento da ONG Esperança possibilitou aplicar, de maneira prática, conhecimentos relacionados ao desenvolvimento Front-End, desde a estruturação das páginas até a publicação da aplicação.

Ao longo do projeto, foram trabalhados aspectos técnicos e visuais, além de questões relacionadas à acessibilidade, responsividade, organização do código, controle de versão e implantação em ambiente de produção.

Dessa forma, o projeto representa a aplicação dos conhecimentos desenvolvidos durante as atividades práticas da disciplina, permitindo compreender de maneira mais ampla as etapas envolvidas na construção e disponibilização de uma aplicação web.
